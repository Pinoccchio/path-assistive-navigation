# Public-data v10 vehicle candidate

The v9 error audit found 75/258 bicycle boxes matched at IoU 0.5 on three previously used COCO validation slices. The size breakdown was 0/35 for boxes under 16 pixels and 0/68 for 16–32 pixels at 512-pixel input, versus 59/92 for boxes at least 64 pixels. On 120 motorcycle-only images, 23 had a bicycle prediction; 25 of 41 bicycle predictions overlapped a motorcycle box at IoU at least 0.3. These are development diagnostics, not independent accuracy estimates. See [the frozen analysis](../runs/public_phase1_v9_coco_train_candidate/failure_analysis/v9_failure_analysis.json).

The [v10 source selection](../data/source/oi_vehicle_v10/train_selection.json) contains 160 small-bicycle and 140 motorcycle candidates from Open Images V7 train, all disjoint by image ID from the v9 Open Images data. All 300 image downloads were checksum verified. The [pre-inference test selection](../data/source/oi_vehicle_v10/test_selection.json) contains 40 bicycle-only and 40 motorcycle-only images from the Open Images test split. A [visual review ledger](../data/source/oi_vehicle_v10/review_exclusions.json) quarantines 16 test and 3 training images whose target label conflicts with the project policy or is too ambiguous. The resulting [v10 dataset](../data/processed/public_phase1_v10_oi_vehicle_candidate/dataset.yaml) preserves all 3,819 v9 images and labels, adds 297 train images, and has 64 new, untouched test images alongside the inherited public test. The standalone vehicle comparison script uses **only the 64 new Open Images test images**.

The Open Images annotations are public research labels and may omit visible objects or include imperfect boxes. Test candidates were reviewed in contact sheets before inference; training contact sheets were sampled, with exact exclusions recorded where found. Training labels are not fully adjudicated instance by instance. The new test is image-ID disjoint from training and from the earlier COCO validation slices, but it is still public internet imagery, not a campus, phone-camera, or walking-assistance benchmark. It cannot establish safety or app readiness. Keep the test selection and review ledger frozen during model comparison.

The 12-epoch GPU training completed successfully on an RTX 3050 Laptop GPU with 512-pixel input, batch 4, and seed 42. The [best checkpoint](../runs/public_phase1_v10_oi_vehicle_candidate/yolov8n/weights/best.pt) is a **research candidate only**. On the [64-image fresh vehicle comparison](../runs/public_phase1_v10_oi_vehicle_candidate/oi_vehicle_test_comparison.json) at confidence 0.25 and one-to-one IoU 0.5 matching:

| Metric | v9 | v10 |
| --- | ---: | ---: |
| Bicycle boxes matched | 29/43 | 30/43 |
| Motorcycle boxes matched | 40/74 | 37/74 |
| Motorcycle-only images with a bicycle prediction | 3/35 | 5/35 |

This is **no promotion**: one extra bicycle match came with three fewer motorcycle matches and two more motorcycle-only false bicycle alerts. The 64-image test contains mostly large bicycles (39/43 boxes had approximate geometric side at least 64 pixels at 512 input), so it did not adequately test the main small-bicycle failure.

To expose that blind spot, an additional [40-image test-split selection](../data/source/oi_vehicle_v10/test_small_selection.json) was frozen after the first result, with all IDs disjoint from the earlier selections. The [separate visual review](../data/source/oi_vehicle_v10/test_small_review_exclusions.json) quarantined nine ambiguous or out-of-policy images before inference. On the [31-image post-hoc diagnostic](../runs/public_phase1_v10_oi_vehicle_candidate/oi_small_bicycle_diagnostic.json), both models matched **11/48 (22.9%)** small bicycle boxes. This slice is diagnostic rather than an independent model-selection test because its size criterion was chosen after inspecting the first test distribution. Larger bicycles and incomplete source annotations make prediction precision on this filtered slice invalid.

The next data work should start with instance-level label QA on the 297 new training images and confirmed small-bicycle misses, not an undirected bulk download. After fixing or excluding noisy annotations, run a controlled resolution/model experiment under a locked independent-source test protocol; measure bicycle recall, motorcycle confusion, and phone latency together. The current Open Images test split is image-ID disjoint but shares the Open Images source with training, so it does **not** satisfy independent-source validation. No v10 export or Infinix X6853 acceptance claim is justified yet. Campus collection remains deferred.

Source provenance: [Open Images V7 download](https://storage.googleapis.com/openimages/web/download_v7.html) and each selected image's original URL, landing page, author, and CC BY license in the frozen selection JSON files.
