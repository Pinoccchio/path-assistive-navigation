# Dataset records

This part of the monorepo contains the existing dataset manifests, source-selection/review records, build reports, configuration and provenance metadata.

Downloaded source images, generated image/label copies, annotation archives, bulk CSV files and Parquet downloads remain local. They total roughly 11GB in the original workspace and are excluded from the initial source-code push. Nothing was deleted locally.

Follow [ml/README.md](../ml/README.md) for acquisition and preparation, [ml/PUBLIC_LABEL_POLICY.md](../ml/PUBLIC_LABEL_POLICY.md) for annotation conventions, and [ml/CAMPUS_CAPTURE_GUIDE.md](../ml/CAMPUS_CAPTURE_GUIDE.md) for independent campus evidence. Check source rights before redistributing image datasets. Dataset configuration may record paths from the original Windows machine; review them before reproducing an experiment elsewhere.
